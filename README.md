# FitLog — Workout Library & Plan Manager

**FitLog** is a dark, no-nonsense gym companion web application built with Next.js. It allows fitness enthusiasts to explore a comprehensive library of lifts, manage daily workout routines with a strict 5-lift cap, save items for later, and track metrics in real-time.

---

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & daisyUI
- **Icons:** Lucide React
- **Notifications:** React Hot Toast
- **State & Persistence:** React Context API & `localStorage`

---

## ✨ Key Features

1. **Dynamic Workout Library:** Fetches and displays twelve specialized lifts covering every major muscle group in a responsive grid layout complete with category tags, equipment lists, and stat badges.
2. **Interactive Detail Pages:** Deep-dive two-column views featuring high-resolution illustrations, equipment specs, difficulty indicators, and ordered step-by-step instructions.
3. **Smart Today's Plan Management:** Lock lifts into your daily routine with a built-in cap of 5 exercises, live-updating metrics for total minutes and calories, and a **"Mark as Done"** workflow.
4. **Advanced Sorting & Tabs:** Seamlessly toggle between "Today's Plan" and "Saved" lists, with custom sorting options for **Duration**, **Calories**, and **Rating**.
5. **Persistent State & Toasts:** Fully synchronized with `localStorage` so your plans and saved workouts survive page reloads, accompanied by instant toast feedback for every action.
